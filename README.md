# Lumière Dental Landing Page

A premium, mobile-first single-page marketing site for a fictional cosmetic and restorative dental clinic in Beirut, built to turn visits into WhatsApp consultations.

## Stack

- Tailwind CSS via CDN for styling
- GSAP + ScrollTrigger for all motion
- One self-contained `index.html` with inline SVG artwork and no raster image payload

## Hero effect

On desktop, the hero pins while a scrubbed ScrollTrigger timeline separates the editorial copy, smile lens, orbit lines, scan marker, and treatment labels into a layered clinical “examination.” Mobile uses a lighter unpinned parallax variant to keep scrolling responsive on mid-range phones.
